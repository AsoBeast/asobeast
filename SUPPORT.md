# Support

- **Questions** about self-hosting, the hosted service, the MCP server or the API go to [Q&A](https://github.com/AsoBeast/asobeast/discussions/categories/q-a).
- **Ideas** for new features go to [Ideas](https://github.com/AsoBeast/asobeast/discussions/categories/ideas).
- **Bugs** go to [GitHub issues](https://github.com/AsoBeast/asobeast/issues/new/choose).
- **Security vulnerabilities** follow [SECURITY.md](SECURITY.md) and are never reported in public.

[Get help](https://docs.asobeast.com/support) in the documentation says what to include in a report.
