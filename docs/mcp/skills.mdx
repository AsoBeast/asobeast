The asobeast plugin adds forty skills to Claude Code. Each one is a method for one ASO or app marketing job, such as an audit, keyword research, metadata writing, competitor tracking, top charts, localization, Apple Search Ads or a launch plan. The skills read your apps, keywords, competitors and charts through the MCP server, so the answers use your numbers instead of generic advice.

## Install the plugin

<Steps>
  <Step title="Connect the MCP server">
    Follow [Connect an agent](/mcp/setup) for Claude Code. A read only token runs every skill; a few steps need write access, see below.
  </Step>
  <Step title="Add the marketplace and install">
    Run in a terminal.
    ```bash
    claude plugin marketplace add AsoBeast/asobeast
    claude plugin install asobeast@asobeast
    ```
  </Step>
  <Step title="Ask">
    Ask for what you need, for example "run an ASO audit of my app in Germany" or "what did my competitors change this week". When you are not sure which skill fits, start with `/asobeast:aso-router`.
  </Step>
</Steps>

## What the skills read

Nine skills fetch data. The other thirty one are methods that work on what you tell them and on what those nine found.

| Skill | Reads |
| --- | --- |
| `aso-audit` | `app_audit`, `metadata_audit`, `app_localizations`, `list_keywords`, `keyword_breakdown`, `competitor_analysis`, `category_ranks`, `ratings_history`, `list_reviews`, `app_actions` |
| `competitor-tracking` | `alert_events`, `competitor_suggestions`, `keyword_comparison`, `competitor_analysis`, `serp_movers`, `serp_snapshot`, `top_chart` |
| `market-movers` and `market-pulse` | `top_chart`, `chart_genres`, `category_ranks`, `serp_movers`, `alert_events`, `portfolio` |
| `android-aso`, `apple-search-ads` and `seasonal-aso` | `keyword_suggestions`, `inspect_keyword`, `list_keywords`, `keyword_discoveries` |
| `asc-metrics` | `change_impact` for the store funnel; sales come from an App Store Connect export you provide |
| `category-positioning` | `top_chart`, `category_ranks` |

The audit skill explains the asobeast audit rather than scoring the listing again, so its numbers match the [ASO audit](/guides/aso-audit) page. Inspecting a keyword, tracking keywords and adding a competitor need a token with the write scope; with a read only token the skills fall back to stored scores or propose the change instead. Store suggestions and keyword inspections spend the allowances described in [MCP tool reference](/mcp/tools).

## What they cannot see

asobeast reports positions, scores and the store funnel. It has no download or revenue estimates, no featured apps and no new release feed, so the skills that mention those ask you for the figures or leave the section out.
